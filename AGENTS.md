## Commands

```bash
bun install              # deps
anchor build             # build program + regenerate target/idl + target/types
anchor test              # TS integration suite on surfpool
cargo test -p opal       # pure Rust unit tests (no validator)
bun run format           # prettier check  (format:fix to write)
cargo fmt --all          # rustfmt
```

CI runs all of these (`.github/workflows/ci.yml`). The web frontend lives in `web/`; see [web/AGENTS.md](web/AGENTS.md).

## Repo map

```
programs/opal/src/
  instructions/   one file per instruction; each exports handler + Accounts + Args
  state/          zero-copy account structs
  settlement.rs   the only code that moves funds out of a bond vault (pure `plan` + `settle`)
  constants.rs    PDA seeds, state/outcome constants (#[constant] → IDL), sentinels
  errors.rs       OpalError
  utils.rs        checked_* math, sentinel helpers
  lib.rs          #[program] entry points
tests/opal.test.ts          the integration suite
target/idl, target/types    generated by `anchor build`
```

Once instructions pass a dozen, group them into `protocol/ assertion/ llm/ vote/` subdirectories by the concept they act on.

## Hard rules — Rust

- **Zero-copy accounts:** always pair `#[account(zero_copy(unsafe))]` with `#[repr(C, packed)]`; the macro alone reorders fields and breaks the TS client's layout. **Primitive fields only** (`u8/u16/u64/u128/i64/Pubkey/[u8; N]`); never `Option`, `bool`, or enums. Use sentinels: `Pubkey::default()`, `0`/`TIMESTAMP_NONE`, `OUTCOME_NONE` (255).
- **One instruction per file** in `instructions/`; export `handler` + `Accounts` + `Args`. Remove imports and constants your change orphans.
- **Constants, not magic numbers.** PDA seeds, states, outcomes and sentinels live in `constants.rs`.
- **Checked math only** on amounts and timestamps (`checked_*` in `utils.rs`); never raw `+ - *`.
- **Errors:** add variants to `OpalError`; give every variant a `#[msg("...")]`.
- **Payouts go through `settlement::settle`.** Change fee or payout rules in `plan` and its unit-test table.
- **Pure logic gets a `cargo test` unit test** (settlement, validators, lifecycle rules) so it is testable without a validator.

## Hard rules — TypeScript tests

- `AnchorProvider.env()` + `anchor.workspace.Opal`; `bun:test` (`describe`/`it`/`expect`/`beforeAll`).
- Keep tests **flat**: nested `describe` blocks interleave with singleton state and cause ordering bugs.
- Cross deadlines with `advanceSeconds()` (surfpool's `surfnet_timeTravel`), never `sleep()`.
- Negative tests assert the exact error name, never a bare `.rejects.toThrow()`.
- Read seeds, states and outcomes from the IDL, not hand-copied constants.

## Gotchas

- **`surfnet_timeTravel` takes milliseconds**, while the on-chain `Clock` is in seconds, and time only moves forward.
- **LLM resolution in tests calls `submit_llm_resolution` directly** with a test resolver keypair. The real resolver service lives in jewl-labs/opal-resolver.
- **Config init is unauthenticated** until the upgrade-authority gate lands; see [docs/architecture.md](docs/architecture.md#known-gaps). Don't "fix" it by comparing the signer with the program ID: the program account can't pay for `init`.
- **The config PDA is a singleton**, so config-rejection tests must run before the suite initializes it.

## Working principles

Bias toward caution; use judgment on trivial tasks.

- **Think first.** State your assumptions; if multiple interpretations exist, surface them rather than picking silently; if something's unclear, stop and ask.
- **Simplest thing that works.** No speculative features, abstractions, configurability, or error handling for impossible cases. If you wrote 200 lines and it could be 50, rewrite it.
- **Surgical changes.** Touch only what the task needs; match surrounding style; don't refactor or reformat unrelated code; clean up only the orphans your own change creates.
- **Verify against a goal.** Turn the task into a checkable outcome (a failing test, a passing command) and loop until it's met.
